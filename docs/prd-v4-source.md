# Source PRD v4.0 (as supplied by the product owner, Hebrew)

> This is the original input specification. The authoritative, research-backed and compliance-adjusted version is `docs/prd-v5.md`.

**מסמך אפיון מוצר מלא ומקיף (Enterprise PRD) — אפליקציית ספורט טלנט (Sport Talent Super-App) — גרסה 4.0**

חזון המוצר: סופר-אפליקציה והרשת החברתית המתקדמת בעולם לספורטאים. המערכת מנהלת אירועי ספורט מבוססי מיקום, מטפלת באמינות השחקנים באמצעות מנוע אמון אוטונומי נטול התערבות אנושית, מספקת אקו-סיסטם של תזונה, מאמנים ומומחים, משלבת שידורים חיים ומדיה חברתית, ותומכת באופן מלא ב-12 שפות.

## 1. ארכיטקטורת אמינות ואלגוריתם אמון אוטונומי
### א. אימות נוכחות כפול (GPS Geofencing + Social Proof)
- דגימת מיקום ברקע משעה לפני המשחק ובדקות הראשונות. משתמש ברדיוס 30–50 מ' מהפין מסומן "הגיע".
- אימות מוצלב דרך ספר הטלפונים: בבעיות קליטה, בדיקה אם באותו תא שטח יש אנשי קשר/חברים מאותו אירוע — אישור נוכחות סופי.
### ב. מדרג סנקציות
- כרטיס צהוב: ביטול מאוחר (<2 שעות) או אי-הגעה לפי GPS.
- השעיה מדורגת: 2–3 צהובים חוסמים הגשת בקשות (שבוע / חודש / לצמיתות).
- Host Reliability: אדמין שפותח אירוע פיקטיבי או מקבל דירוגים שליליים — נשללות זכויות פתיחת קבוצות לצמיתות.
- Anti-Toxicity Shadowban: 3 שחקנים שונים סימנו "אלים/לא ספורטיבי" → Shadowban מיידי (מוסתר מהמפה ואינו רואה מגרשים/קבוצות/שחקנים).

## 2. מפת עולם חכמה וניהול מגרשים
- סינון ענפים (כדורגל, כדורסל, טניס, ריצה...) עד 3 בו-זמנית.
- רדיוס 1/2/5/10/30/50 ק"מ או דיפולט GPS; פינים דינמיים לפי ספורט.
- תכנון ניידות גלובלי: הצטרפות לאירועים בעיר/מדינה אחרת שבועות מראש.
- דירוג מתקנים 1–5 (דשא, תאורה, רשתות; טניס: חימר/בטון/דשא; כדורסל: טבעות ורשתות).
- דיווח Waze-style "אין כאן מגרש" — 3 דיווחים שונים → הסרה אוטומטית.

## 3. מחזור חיי משחק, מאצ'מייקינג וצ'ט
- הרשמה: OTP בטלפון.
- יצירת אירוע: מגרש, ספורט, ציבורי/פרטי, כמות שחקנים, תאריך.
- הזמנה: וואטסאפ, פייסבוק, או מרשימת משתתפים קודמים.
- בקשת הצטרפות → פוש לאדמין; אישור/דחייה → פוש לשחקן.
- Smart Squad Balancing לפי דירוגים (מהירות, שליטה, ציון כללי) ותפקיד (שוער, בלם, קשר, חלוץ, רכז, סנטר...).
- עדכון תוצאה עד שעתיים מסיום.
- צ'ט זמני נמחק 2–4 שעות אחרי המשחק.
- מסנן NLP רב-שפתי: חסימת קללות/איומים לפני שליחה; חזרה → כרטיס צהוב והשעיה מהצ'ט ל-24 שעות.

## 4. מדיה חברתית, שידור חי ומצלמות גוף
- העלאת מדיה עד שעתיים מסיום — אחר כך הגלריה ננעלת.
- Post-Match Vault: היסטוריית מדיה לכל מגרש עם סינון תאריכים.
- תיוג שחקנים בכפוף לאישור.
- שידור חי מהסמארטפון / GoPro.

## 5. אקו-סיסטם: תזונה, מאמנים ומומחים
- עסקים תומכי ספורט במפה + קופונים חד-פעמיים לשחקנים שסיימו משחק סמוך.
- מרקטפלייס מאמנים, תזונאים, פיזיותרפיסטים; פרופיל, תעודות, חוות דעת, הזמנות; דירוג רק ממשתמשים שקיבלו שירות.

## 6. 12 שפות
עברית (RTL), ערבית (RTL), אנגלית, ספרדית, סינית (מפושטת+מסורתית), יפנית, פורטוגזית, רוסית, צרפתית, איטלקית, גרמנית, הינדית. Native mirroring, תרגום הודעות צ'ט, זיהוי שפת מערכת.

## 7. מסכים
מפה ראשית; פרופיל (כרטיס ירוק/צהוב/אדום, סטטיסטיקות, תפקיד, היסטוריה, מדיה); תפריט צד (הגדרות, שפה, התראות, Dark/Light, מועדפים); Explore/Reels; Network/Friends.

## 8. מונטיזציה
פרסום מבוסס מיקום; חסויות מתחמים וטורנירים; Sport Talent Pro (Heatmaps, גרפים, אחסון); Boosted Events.

**Product owner decisions (this project):** Web + Android + iOS from one codebase; Expo + Supabase; global launch day one with all 12 languages and all payment methods; compliance-driven adjustments allowed when documented.
